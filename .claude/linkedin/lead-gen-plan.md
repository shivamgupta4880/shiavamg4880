## 2. Who to target (LinkedIn search)

### A. People already asking for a developer (warmest leads)

Search bar -> **Posts** tab -> sort by **Latest**. Try each:

```
"looking for a developer"
"need a web developer"
"looking for a MERN developer"
"need help with my React app"
"looking for a freelance developer"
"technical co-founder" MVP
```

Reply under the post (use the comment template below) and then send a connection note.

### B. Founders of small startups

Search bar -> **People** -> **All filters**:

- Keywords (boolean):
  `("founder" OR "co-founder" OR "CEO") AND ("startup" OR "SaaS" OR "MVP") NOT ("developer" OR "agency" OR "recruiter")`
- Company size: **1-10**, **11-50**
- Industry: Software Development, Technology/Internet, E-commerce, Education
- Location: {{e.g. United States, United Kingdom, India}}
- Connections: 2nd

Pick 10 a day max. Open the profile and note one specific thing (a recent post,
product launch, hiring post) before writing to them.

### C. Small businesses without a good website

- Keywords: `owner` + {{a niche: clinic, restaurant, coaching, real estate}}
- Location: {{your city / region}}
- Check their website first. Only reach out if it's slow, broken on mobile, or missing.

### Comment on a "looking for a developer" post

```

```

### Connection note (under 200 chars)

```
Hi {{name}}, saw your post about {{specific thing}}. I'm a MERN developer who builds and ships web apps for early startups. Would love to connect.
```

### First message (after they accept)

```
Thanks for connecting, {{name}}.

I noticed {{specific thing: their product / post / website issue}}. I build full-stack web apps (React, Node, MongoDB) and deploy them with Docker.

Recently I built {{project}} which {{what it does}}.

Is {{problem you could solve}} something you're working on right now? If not, no worries at all.
```

### Follow-up 1 (4-5 days later, no reply)

```
Hi {{name}}, quick follow-up. If it helps, I can send a short breakdown of how I'd approach {{their problem}}, free, no call needed.
```

### Follow-up 2 (7 days after that, last one)

```
Last note from me, {{name}}. If a web app build or fix comes up later, I'm here. Good luck with {{their product}}.
```

Stop after follow-up 2. Never send the same message to everyone; the
`{{specific thing}}` is what gets replies.

## 5. Daily routine (30 min)

| Time | Task |
|---|---|
| 10 min | Search A (posts asking for devs), comment + connect on 3-5 |
| 10 min | Search B or C, send 5-10 personalised connection notes |
| 5 min | Reply to DMs, send follow-ups that are due |
| 5 min | Comment on 3 posts from founders in your niche |

Track every lead in a sheet: name, link, date contacted, stage
(connected / replied / call / won / lost), next follow-up date.

Limits: keep connection requests under ~15 a day and 100 a week to stay well
inside LinkedIn's limits.
